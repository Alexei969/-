1. Проверка дублей: Убедился, что если order_id встречается дважды, он учитывается в колонке orders только один раз.
2. Проверка выручки: Сверил, что отмененные заказы (cancelled) учитываются в колонке orders, но НЕ прибавляются к revenue.
3. Контрольные суммы: Проверил, что сумма всех заказов в итоговом файле совпадает с количеством уникальных order_id в исходном файле.
4. Сортировка: Проверил, что итоговый файл отсортирован сначала по артикулу (sku), а затем по дате.
5. Дубли строк: В выгрузке есть повторяющиеся order_id. Скрипт запоминает уже обработанные ID и пропускает их (заказ считается только 1 раз).
6. Разный регистр статуса: Встречаются delivered, Delivered, DELIVERED, а также canceled, Cancelled и т.д. Я привел все статусы к нижнему регистру (.lower()) и заменил canceled на cancelled.
7. Пустой quantity: В некоторых строках нет количества товара. Такие строки я решил полностью пропускать, так как без количества нельзя посчитать ни заказы, ни выручку.
8. Лишние пробелы: В конце некоторых строк есть пробелы. Я использую метод .strip(), чтобы очистить данные перед обработкой.
9. Использовал Claude для написания черновика кода
